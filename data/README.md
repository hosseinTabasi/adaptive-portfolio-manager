# Data

- `cache/` — per-ticker Yahoo CSV (gitignored). Regenerated by `src.data_loader`.
- `processed/prices.csv`, `processed/returns.csv`, `processed/meta.json` — small cleaned panel from the last run.

If `meta.json` has `"label": "TOY"`, every result in `results/` for that run must be treated as synthetic. The run that shipped with this repository is FULL-public Yahoo, 2021-01-04 to 2026-08-28, ten tickers, no synthetic bond.
